# Amazon S3

Kite provides Amazon Simple Storage Service (S3) emulation supporting bucket and object operations with notification triggers.

## Overview

The S3 service uses the standard RESTful HTTP protocol, handling requests based on the path structure and SigV4 authorization header.

**Routing:**
- Path-based: `/{bucket}` and `/{bucket}/{key}`
- SigV4 service name: `s3`

## Supported Operations

| Operation | HTTP Method | Path | Description |
|-----------|-------------|------|-------------|
| List Buckets | `GET` | `/` | List all S3 buckets |
| Create Bucket | `PUT` | `/{bucket}` | Create a new bucket |
| Delete Bucket | `DELETE` | `/{bucket}` | Delete an empty bucket |
| List Objects V2 | `GET` | `/{bucket}?list-type=2` | List objects in a bucket |
| Put Object | `PUT` | `/{bucket}/{key}` | Upload an object |
| Get Object | `GET` | `/{bucket}/{key}` | Download an object |
| Delete Object | `DELETE` | `/{bucket}/{key}` | Delete an object |
| Head Object | `HEAD` | `/{bucket}/{key}` | Get object metadata |
| Put Bucket Notification | `PUT` | `/{bucket}?notification` | Set bucket notifications |
| Get Bucket Notification | `GET` | `/{bucket}?notification` | Get bucket notifications |

## Configuration

### Creating a Bucket via Builder

```csharp
builder.AddS3Bucket("my-bucket");
```

### Creating a Bucket via AWS SDK

```csharp
var s3Client = new AmazonS3Client(
    new BasicAWSCredentials("test", "test"),
    new AmazonS3Config { ServiceURL = "http://localhost:4566", ForcePathStyle = true });

await s3Client.PutBucketAsync("my-bucket");
```

> **Note:** Always use `ForcePathStyle = true` when connecting to the emulator, as virtual-hosted-style requests are not supported.

## Object Operations

### Uploading an Object

```csharp
await s3Client.PutObjectAsync(new PutObjectRequest
{
    BucketName = "my-bucket",
    Key = "documents/report.pdf",
    FilePath = "/path/to/report.pdf"
});
```

### Downloading an Object

```csharp
var response = await s3Client.GetObjectAsync("my-bucket", "documents/report.pdf");
using var stream = response.ResponseStream;
// Read the stream...
```

### Listing Objects

```csharp
var response = await s3Client.ListObjectsV2Async(new ListObjectsV2Request
{
    BucketName = "my-bucket",
    Prefix = "documents/"
});

foreach (var obj in response.S3Objects)
{
    Console.WriteLine($"{obj.Key} ({obj.Size} bytes)");
}
```

### Deleting an Object

```csharp
await s3Client.DeleteObjectAsync("my-bucket", "documents/report.pdf");
```

## S3 → Lambda Trigger

Set up notifications to trigger Lambda on object events:

```csharp
builder
    .AddS3Bucket("uploads")
    .AddLambda("FileProcessor", lambda => lambda
        .WithHandler("MyAssembly::MyNamespace.Function::Handler")
        .WithDll("/path/to/assembly.dll"))
    .AddS3Trigger("uploads", "FileProcessor", S3EventType.ObjectCreated);
```

### Supported Event Types

| Event Type | Description |
|-----------|-------------|
| `S3EventType.ObjectCreated` | Any object creation event |
| `S3EventType.ObjectRemoved` | Any object removal event |

When an object event matches a configured trigger, the Lambda function is invoked with the standard S3 event notification format.

## Storage

All objects are stored in memory. Data does not persist across emulator restarts.
